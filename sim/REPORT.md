# Simulator report

Generated by `node sim/run.mjs --runs 2000 --seed 1`: 2000 games per farm, difficulty and flock size (126000 games), played strictly by `docs/CORE-RULES.md` with the default flock policy (`sim/policy.mjs`). Same seed, same report.
